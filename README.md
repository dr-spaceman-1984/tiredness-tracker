# Tiredness Tracker

A single-file, phone-friendly webpage for morning and evening energy check-ins, with optional work-travel and cycle notes. It requires no app installation, build step, account, or server-side code.

## Open the page

Open `index.html` in a web browser to use it on this computer. To open it on a phone from a link, the file must be placed at a web address. That requires a static hosting service; the page itself does not need to be installed on the phone. Once hosted, she can simply visit the link in Safari or Chrome.

## Data

Entries are saved in browser storage on the device. There is no login, server, analytics, or automatic sync. Each device/browser has its own log, and clearing browser data may erase it.
